FEATHER OBJECT MODEL · VERSION 0.2 · RUST DOMAIN + RUNTIME OBJECTS · API-FACING

Objects between providers, storage, and React

The object model is the neutral Rust layer. It prevents provider records and database rows from leaking into the UI, while keeping session identity, metric continuity, live process state, and embedded terminal state explicit.

Core rule: a Session is durable provider activity identified by { providerId, sid }. A Console is a temporary PTY attached to that session. Closing or reopening a console never creates, deletes, or resets the session.

Object flow

Provider source

JSONL, rollout files, SQLite, process listings, account sources.

→

Private adapter objects

Provider-shaped parser records. Never cross the adapter boundary.

→

Neutral domain objects

Session, metrics, live observations, project summaries, consoles.

→

API DTOs

Tauri command responses and events consumed by React.

Persistence stores current session/account/project projections. Runtime stores process observations, PTYs, and bounded scrollback.

Provider and persistence boundaries

ProviderAdapter

private input boundary

Returns neutral SessionCandidate, account data, capacity, source signatures, and safe resume commands. It never returns provider-shaped objects to services or React.

Persistence mapper

database ↔ domain boundary

Maps (provider_id, sid) to SessionKey, project foreign keys to ProjectKey, metric state to typed variants, and live columns to observations. Consoles and scrollback are not tables.

ProjectionService

domain → API boundary

Builds SessionRow, ProjectSummary, StatusSnapshot, ConsoleSummary, and error DTOs. It is the only layer that shapes objects for Tauri.

ConsoleService

PTY ownership boundary

Owns process launch, input/output bytes, resize, bounded scrollback, attach/detach registry, exit, and shutdown. It never calculates metrics or creates a durable session on its own.

Object-model invariants

✓ Session identity always uses provider + complete sid.

✓ Reopen/resume creates a Console, never a duplicate Session.

✓ Closing a Console does not erase metrics or source data.

✓ Live means provider process open anywhere, not Pigeon console attached.

✓ Recent uses closed_at_ms, not merely last_active_ms.

✓ Project KPIs are recalculated from summed counters.

✓ Terminal bytes and credentials never enter ordinary DTOs.

✓ React renders the terminal; Rust owns PTY behavior and replay.
